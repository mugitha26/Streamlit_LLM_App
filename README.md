# Week 14 - Streamlit LLM App

## Project Title
AI PDF Question Answering System

## Domain
Education

## Objective
To create an interactive web application using Streamlit,
LangChain, ChromaDB and Ollama.

## Technologies Used
- Python
- Streamlit
- LangChain
- ChromaDB
- Sentence Transformers
- Ollama
- PyPDF
- Pandas

## Features
1. Custom title and sidebar
2. PDF upload
3. PDF validation
4. Multiple PDF upload and selection
5. PDF filename and page count
6. Clear Chat History
7. Conversation history
8. Retrieved document chunks
9. Response generation time
10. CSV storage

## Models
Embedding Model: all-MiniLM-L6-v2

LLM Model: llama3.2:3b

## How to Run

Install libraries:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Conclusion
The interactive PDF Question Answering application
was developed successfully using Streamlit,
LangChain, ChromaDB and Ollama.
